# Settlement Reconciliation Agent

An architecture-first project for the Razorpay Buildathon AI Finance Controller track. It will deterministically reconcile merchant orders, Razorpay settlement ledger transactions, settlement batches, and bank credits; surface evidence-backed exceptions; and let an AI controller explain findings without performing financial arithmetic.

Status: **architecture proposed; implementation is intentionally blocked pending owner approval**.
